This is my assignment and it combines different Python programming techniques to create a structured and reusable solution for retail-related tasks.
## Project Objectives
The main objectives of this project are:
- Automate basic retail calculations using Python.
- Calculate sales taxes for retail transactions.
- Categorize customer orders based on order size.
- Manage customer information using Python data structures.
- Check inventory using a custom Python module.
- Maintain audit information using file handling.
- Implement store branch management using Object-Oriented Programming.

## How to Run the Project
Follow these steps to execute the project:
1. Clone or download this GitHub repository.
2. Open Google Colab or Jupyter Notebook.
3. Upload the `Urban_Retail_Analytics_System.ipynb` notebook.
4. Make sure `inventory_utils.py` is available in the notebook's working directory.
5. Run the notebook cells sequentially.
6. Review the generated outputs.
7. Check the `audit_log.txt` file for audit information.
