# Urban Retail Analytics System
Python Module End Assessment 1 – Advanced Data Science Program

An automated Python solution for Urban Retail to compute sales taxes,
categorize order sizes, manage customer data, handle inventory with a
custom module, and model store branches using OOP.

## Files
- Urban_Retail_Analytics_System.ipynb – complete code with outputs
- inventory_utils.py – custom module with the check_stock() function
- audit_log.txt – audit log created by the file handling task

## Topics Covered
1. Basic syntax: input, type casting, conditions
2. Loops (break/continue), functions, lambda, recursion
3. Tuple, set, dictionary, list comprehension, file and error handling
4. Built-in modules (random, datetime) and a custom module
5. OOP: classes, encapsulation, inheritance, polymorphism
